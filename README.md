# Plan Maker

Приложение, которое составляет план тренировки на день и показывает каждое упражнение в 3D.
Версия 0.1: тема «Спортзал», без ИИ, всё хранится на телефоне.

## Что уже есть

- Анкета: цель, опыт, дома или в зале, сколько времени.
- План на день по правилам: дни чередуются (ноги и грудь, спина и руки, всё тело), подходы и отдых зависят от цели.
- Кнопка «Заменить»: приложение запоминает, какие упражнения ты не любишь.
- Тренировка по шагам: 3D-показ, подходы, таймер, отдых, подсказки по технике.
- 11 упражнений с 3D-анимацией.

## Как запустить

```bash
npm install
npx expo start        # телефон: приложение Expo Go, отсканировать QR-код
npx expo start --web  # в браузере
```

## Устройство

- `src/app/` — экраны (Expo Router).
- `src/data/exercises.ts` — упражнения: шаги, ошибки, анимация.
- `src/logic/plan.ts` — составление плана без ИИ.
- `src/three/animations.ts` — позы 3D-человечка для каждого упражнения.
- `assets/models/coach-male.glb`, `coach-female.glb` — 3D-тренеры (парень и девушка). Собраны скриптом `tools/character/build.py` из бесплатной базы MakeHuman (лицензия CC0): тело, скелет в формате Mixamo, одежда и кроссовки.
